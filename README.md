# House Price Prediction from Scratch

A machine learning project where I implement Linear Regression
and Gradient Descent from scratch using NumPy to predict house prices.

## Current Progress

- Data cleaning
- Exploratory data analysis
- Feature selection
- Train/test split
- Feature scaling
- Linear Regression from scratch
- Gradient Descent from scratch
- Cost function
- MAE, RMSE and R² evaluation
- Learning-rate experiments
- Data visualization

## Model

The current model uses 12 numerical features including:

- Bedrooms
- Bathrooms
- Living area
- Lot area
- Floors
- Waterfront
- View
- Condition
- Above-ground area
- Basement area
- Year built
- Year renovated

## Current Results

| Metric | Result |
|---|---:|
| MAE | ~$159,655 |
| RMSE | ~$243,564 |
| R² | ~0.601 |

These results represent the current baseline model.

## Goal

The purpose of this project is to understand the fundamentals of
machine learning by implementing the algorithms and training process
rather than relying entirely on high-level machine learning libraries.
